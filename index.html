Manage

  • Users: create / view / edit / delete users and their author and reviewer profiles (ORCID, research areas, expertise, experience, reviewer pools).
  • Papers: create / view / edit / delete papers with their authors (order, corresponding author), keywords, session and versions.
  • Reviews: create / view / edit / delete completed reviews.
  • Sessions: create / view / edit / delete sessions and assign accepted papers to them.
  • Schedule: output of the database view accepted_paper_schedule.
  • Conferences & tracks: read-only seed data (hosts, tracks, reviewer pools, sessions).

Demonstrating the two required application checks (seed data)

  1. Self-review is rejected — add a review for paper #2 with reviewer Arman Armanov (he is the first author of paper #2). Also: edit paper #1 and add Arman Armanov as an author (he already reviewed paper #1).
  2. Invalid session assignment is rejected — open session #1 (CADS 2026) and assign paper #9 (status submitted) or paper #10 (accepted, but in ISMLS 2026). A valid assignment: paper #4 (accepted, CADS 2026, no session yet). Also: edit paper #1 (scheduled in session #1) and change its status to rejected or its track to an ISMLS 2026 track.
